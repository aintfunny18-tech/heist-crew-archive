# Content model

## Dossier tabs

Each operative uses the same six-tab structure:

1. Overview
2. Abilities
3. Equipment
4. Spells
5. Notes
6. Relationships

There is no character-level Operations tab and no role-specific specialty tab.

## Operations

Operations are crew-wide records. The archive launches with the honest empty state: **No operations archived. The crew has not yet entered the field.**

## Whiteboard

The whiteboard is a noncanonical scratch surface. It does not persist on refresh and does not imply that an initial approach survived contact with the mission.

## Archive

Assets, Intel, and Timeline live under one lower-frequency Archive route rather than occupying separate primary-navigation positions. Each launches empty until campaign play creates real records.
